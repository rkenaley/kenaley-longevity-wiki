## 🚀 Quickstart & Local Usage

Because the wiki is pure HTML5, modern CSS, and vanilla JavaScript, you can run it immediately without installing any software or dependencies:

### Option A: Direct Browser Opening (Instant)
Simply double-click [`index.html`](index.html) in your file manager to open it in Chrome, Edge, Safari, Firefox, or Brave.

### Option B: Local HTTP Server (Optional)
If you prefer testing over a local HTTP server:
```bash
# Using Python (standard on Windows/macOS/Linux):
python -m http.server 8080

# Or using Node.js:
npx serve .
```
Then navigate to `http://localhost:8080` in your web browser.

## 🌐 Deploying to GitHub Pages (Free One-Click Hosting)

You can host this entire interactive wiki publicly or privately on GitHub Pages:

1. **Create a new repository** on GitHub (e.g. `kenaley-longevity-wiki`).
2. **Push this directory** to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "feat: Kenaley Longevity Protocol v5.0 complete interactive wiki"
   git branch -M main
   git remote add origin https://github.com/<your-username>/kenaley-longevity-wiki.git
   git push -u origin main
   ```
3. **Enable GitHub Pages:**
   * Go to your repository settings on GitHub: **Settings** &rarr; **Pages**.
   * Under **Build and deployment** &rarr; **Branch**, select `main` and root `/`.
   * Click **Save**.
   * Your site will be live at `https://<your-username>.github.io/kenaley-longevity-wiki/` within 60 seconds!
